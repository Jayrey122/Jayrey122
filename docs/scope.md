# Project Scope Statement

## Project Purpose

Create a personal website that introduces me, Jazmine Reynolds, and demonstrate an understanding of HTML. The project will use the scoping to define the websites purpose, goals, and limitations before development begins.

## Description

The project will create a webpage called 'index.html.' The website will introduce me, Jazmine, and describe my academic and career goals, lost my hobbies, and include a hyperlink to GitHub.

The webpage will contain a title, headings, paragraphs, an unordered list, and a hyperlink.

## Desired Results

- A valid HTML document that opens successfully in a web browser.
- At least two paragraphs describing academic or career goals.
- At least three hobbies or interests.
- A clearly organized webpage using HTML elements.
- A ZIP file containing 'scope.md' and 'index.html'.

## Exclusions

- Multiple webpages.
- A resume or complete biography.
- Videos and audio.
