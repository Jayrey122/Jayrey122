# Project retrospective

## Project Name

Jazmine Reynolds Personal Portfolio Website

## What Went Well

One thing that went well during this project was creating a personal portfolio website that represents my background, interests, and career goals. I was able to create two connected web pages a homepage and an About Me page. The homepage introduces my professional interests, technology skills, hobbies, and selected projects. The About Me page gives more information about my experiences working in special education and my goal of becoming a high school Algebra teacher.

Another success was using HTML and CSS to organize and style the website. I used headings, paragraphs, lists, links, navigations, images, a footer, and a contact box. I also used one external stylesheet so both pages would have a consistent design. Creating the website helped me become more comfortable using VS Code, GitHub Desktop, GitHub repositories, and HTML/CSS files.

I was also able to include links to other projects I created including my gamification and simulation knowledge base, Canva website, Canva presentation, and GitHub profile. Adding these projects made my portfolio feel more complete and gives visitors a way to see other work I have completed.

## What Went Wrong

One challenge during this project was making sure that every required file was included and placed in the correct folder. The final project required multiple website files, Markdown documents, a README file, GitHub links, screenshots, and a ZIP file. Keeping track of all of these requirements took time and careful planning.

Another challenge was working through small HTML and CSS problems. At times it was difficult to understand why a section did not appear correctly, why a box did not have the expected style, or why a link was not working. I had to check the spelling of the file names, HTML tags, CSS class names, and links carefully. Small errors can affect how a website displays so I learned that saving and testing my work often is important.

Managing time was also challenging because I had to balance schoolwork with work, family responsibilities, and other commitments. This made it important to break the project into smaller tasks instead of trying to complete everything at one time.

## What I would do differently

For my next project I would start building and testing the website earlier. I would create a checklist from the assignment instructions before I begin so I can clearly track every required item including documentation, HTML pages, CSS, screenshots, links, and the final ZIP file.

I would also make more frequent GitHub commits while I work. Making regular commits would help me save progress, keep track of changes, and make it easier to return to an earlier version if I accidently chage or delete something important.
